ParaNav - base map for the TOPO screen
======================================

1. Copy the "maps" folder (with its contents) to the root of the SD card:
      SD card/maps/<area>/info.txt
      SD card/maps/<area>/z10.pak ... z14.pak
   Either with a card reader or with ParaNav: Menu > System > USB mode.
2. On the device: Menu > System > Reload data from SD (after USB mode this happens automatically).
3. The TOPO screen (after the MAP screen) shows the map while you are inside the map area.

The preview_*.png files show a part of the map around the area centre - no need to copy them.

Map data: (c) OpenStreetMap contributors, ODbL licence (openstreetmap.org/copyright).
The map is an orientation aid, not an aeronautical chart - obstacles may be incomplete.
